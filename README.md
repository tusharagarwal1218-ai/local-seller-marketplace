Local Seller Marketplace

A multi-vendor local marketplace connecting customers with local sellers.

Project

Customers can discover products from local sellers, compare products, place orders, and track their orders.

Sellers can create their shops, list products, manage inventory, and process orders.

Administrators can manage sellers, customers, products, orders, categories, payments, delivery, and marketplace settings.

Main Applications

- Customer App
- Seller App
- Admin Panel
- Backend API
- Database
- Shared Services
